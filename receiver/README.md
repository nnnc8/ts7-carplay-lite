# TS7 CarPlay Lite v0.1-alpha receiver

**TECHNICAL PREVIEW — NOT YET A FUNCTIONAL CARPLAY RECEIVER.**

Original Java/framework implementation for Android 8.1 / API 27 / ARMv7.
No upstream protocol core or authentication identity is bundled. The explicit
`ReceiverCore` boundary refuses connections while lawful authentication is unavailable.
See [research](../docs/CARPLAY_IMPLEMENTATION_RESEARCH.md) and
[architecture](../docs/WIRELESS_CARPLAY_ARCHITECTURE.md).

The developer-only, generated 1280×720 H.264 pattern exercises the same bounded
compressed-input queue, SPS/PPS/IDR handling, MediaCodec and Surface path intended
for a future lawful core. Test playback never changes CarPlay state to STREAMING.

## Build and test

Install Android SDK platform 27 and build-tools 35.0.0; use JDK 17+, Python 3 and zip.

```sh
./receiver/test.sh
TS7_CARPLAY_UPLOAD_URL=https://ts7-carplay-lite-relay.vercel.app/api/carplay-diagnostics ./receiver/build.sh
```

Output: `dist/TS7-CarPlay-Lite-v0.1-alpha.apk`. The APK has Java DEX only and no
native ABI filter; it runs on `armeabi-v7a` without a host-architecture native library.
Builds pin the SDK API and tools. Signing uses an ignored, persistent local test key;
unsigned byte-for-byte comparison is separate from test-signature reproducibility.

The synthetic test asset is generated by `generate-pattern.sh` using FFmpeg/libx264,
and contains only synthetic color bars, motion and a relative time counter. Neither tool is bundled.
The normal app opens idle. Settings → Developer test mode is an explicit local opt-in.
No other media files are read. No microphone, location or account permission is requested.

Diagnostics export only fixed event/error codes, hardware counters and radio metrics.
Upload requires a confirmation and uses the server-fixed Issue #13 destination;
it never sends identifiers or credentials. Ring capacity is 500; upload exports the
newest 200 events to remain below 32 KiB. Offline copy works without the relay.

## Current limits

- Wireless shell implemented; actual iPhone discovery/bootstrap/session unavailable.
- Authentication: `BLOCKED_BY_AUTHENTICATION_REQUIREMENT`.
- Media audio interface: AudioTrack PCM; real media audio is incomplete/untested.
- Touch coordinates implemented; real CarPlay delivery unverified.
- Microphone/Siri interfaces deferred; no capture permission or implementation.
- Recovery/watchdog bounded; TS7 vendor behavior and sustained playback need device tests.
