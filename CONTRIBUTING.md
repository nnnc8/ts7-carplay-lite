# Contributing

This is currently a hardware-specific experimental project.

Before contributing, read `AGENTS.md` and `PROJECT_STATUS.md`. Changes should stay focused on the TS7 / SL8141E / Android 8.1 target unless a separate compatibility layer is explicitly justified.

For bugs, include exact build/version, reproduction steps, and whether the issue is wired or wireless. For runtime failures, include the diagnostic report when safe to share.

Do not submit proprietary TLink/ZLink APK contents, Apple authentication secrets, certificates, device identifiers or private network information.
